QUÉ ES LA CAPA 7

La capa 7 define cómo una aplicación solicita, envía y recibe información.

ProtocoloPara qué sirve
HTTP / HTTPSPáginas web y APIs
DNSResolver nombres como google.com a direcciones IP
SMTPEnvío de correo electrónico
IMAP / POP3Recepción y acceso al correo
FTPTransferencia de archivos
SSHAcceso remoto seguro
DHCPConfiguración automática de red
SNMPMonitorización y administración de dispositivos
